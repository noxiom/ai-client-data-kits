# AI and client data: kits for small firms

Free, maintained templates and checklists for the moments a 10-50 person firm actually runs into with AI tools and client data. Each kit answers one situation, in plain language, with its sources and the date they were checked.

**This repository is public.** Anyone can read, copy and reuse it under the licences below. **Start on the website, not here:** Every kit has a page on noxiom.com with the answer first and downloads in Word. This repository is the source those pages are built from: use it to reuse the material, see every change, or send a correction.

| Situation | Web page | Status |
|---|---|---|
| Someone put client data into an AI tool | [For the firm](https://noxiom.com/ai-data-incident) and [for staff](https://noxiom.com/pasted-company-data-into-ai) | Live (1.0.0, 23 Nov 2026) |

## How it's built

```
guide/           the AI accounts guide: its dataset (data/ai-accounts.json, 40 vendor sources,
                 every fact dated), renderer, templates, register and tests
data/            one JSON file per kit: the text, the steps, the factors, the sources
kits/<kit>/      the templates as Markdown (generated from data/; edit the data)
templates/       kit page templates, styles and the browser-only scripts
src/             kit renderer (pages, Word files, Markdown, JSON Schema), a local preview
test/            what must always hold: sources, dates, wording rules, privacy, valid files
site/            rendered output that is copied into the website (generated, kept for reference)
```

Node 22 or later, no install step:

```bash
node src/render.mjs                    # kit pages, Word files, Markdown, schema
node --test 'test/*.test.mjs'          # kit tests
cd guide && node src/render.mjs        # guide pages, data, Excel register
cd guide && node --test 'test/*.test.mjs'   # guide tests
node src/preview.mjs path/to/website   # local preview of everything inside a copy of the live site
```

The kits read the guide's dataset in place, so the kits and the guide never disagree. The website itself lives in a separate, private repository; it receives the rendered files from `site/` and `guide/site/`.

## For AI assistants

The incident record's questions and allowed answers are a JSON Schema at https://noxiom.com/data/ai-incident-record.schema.json (generated by `src/render.mjs`). An assistant can interview someone, produce the JSON, and the person pastes it into the page, which checks every value. The dataset behind the guide is at https://noxiom.com/data/ai-accounts.json.

## The rules every kit follows

- **Sourced and dated.** Legal and vendor statements cite the primary source and the date it was read. Gaps are stated as gaps.
- **No verdicts.** No tool is called safe, compliant or certified. The incident kit lists factors; the firm decides.
- **No fear.** No fines, no countdown theatre, no urgency that the rules don't create.
- **Nothing collected.** Interactive parts run in the browser, send nothing and store nothing. They never ask for real client data.
- **Not legal advice.** For a decision with legal consequences, involve a privacy officer or lawyer.
