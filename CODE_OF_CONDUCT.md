# Code of conduct

This repository exists to help small firms handle AI tools and client data well. Contributions and corrections are welcome from anyone.

- Be accurate. Point to the source for any fact, and say when something is your judgement.
- Be kind and specific. Criticise the text, not the person.
- Never post client data, names or details of a real incident, yours or anyone else's.
- No selling in issues or pull requests.

Problems with someone's behaviour here: email contact@noxiom.com. We may edit or remove comments, and block accounts, that break these rules.
